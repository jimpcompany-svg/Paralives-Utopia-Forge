### 📡 IV. Seamless Integration & Accessibility

## ⚙️ Quickstart – Igniting the Forge

**Prerequisite:** Ensure your creative environment is at a stable "unlocked" state.

1.  **Deploy the Module:** Place the module archive into your designated `Mods/Plugins` directory. The loader will automatically index it as a "Structural Utility."
2.  **Prime the Resonance:** Launch the environment. Find the new **"Furnace"** icon on the bottom-right of the build bar.
3.  **Tune the Dial:** Open the "Abundance Dial" and set it to **"Harmonized"** (our alternative to "unleashed resources").
4.  **Begin the Craft:** Select any foundation piece. You'll notice the "Ghost Grid" has shifted color, indicating the Resonance Core is active.
5.  **Express Yourself:** Conversely, to restrict variables for a challenge build, use the "Strict Mode" to engage realistic physics.
